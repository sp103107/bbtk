# UI Research Reference v0.7.1

This document records research-derived UI patterns used for the v0.7.1 hardening pass.

## Patterns used

| Pattern | Applied as |
|---|---|
| Shared tablet/kiosk | Employee Kiosk panel and large tap buttons |
| PIN sign-in | Employee ID + PIN remain primary identity inputs |
| One-button punch | Clock In, Clock Out, Start Break, End Break buttons remain simple |
| Clear activity status | Employee status strip and success receipt |
| Export/report owner surface | Grouped owner dashboard cards |
| Easy navigation | Task-based owner panels and hidden technical JSON |

## Boundary

No vendor UI assets, code, screenshots, logos, or proprietary layouts were copied. The research was used only to guide generic UX patterns.
