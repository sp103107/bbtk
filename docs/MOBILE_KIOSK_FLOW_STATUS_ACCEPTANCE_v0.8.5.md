# Mobile/Kiosk Flow Status Acceptance — v0.8.5

## Acceptance rules

- Employee can see the punch sequence before tapping a button.
- Receipt state is visible after a punch attempt.
- Offline recovery state explicitly says pending owner review.
- Owner console flow communicates task order without hiding required review.
- Technical JSON remains hidden by default.

## Non-claims

This is static UI/UX validation. No browser screenshot, visual regression pass, deployment, or production readiness is claimed.
