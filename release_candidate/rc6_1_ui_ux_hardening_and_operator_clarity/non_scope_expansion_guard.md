# No-Scope-Expansion Guard v0.7.1

This bump is limited to frontend hardening and operator clarity.

## Forbidden additions

- Payroll-provider integration.
- GPS/geofence implementation.
- Camera/selfie capture.
- Biometric identity.
- Native mobile app.
- Production deployment claim.
- Legal, cannabis, or payroll compliance seal.

## Allowed additions

- Static HTML/CSS/JS improvements.
- Frontend surface contracts.
- UI copy validation.
- Accessibility static checks.
- No-scope-expansion validation.
